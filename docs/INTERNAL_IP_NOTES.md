# Internal Product and IP Notes

**Internal working notes — not a legal opinion, patentability analysis, or
freedom-to-operate assessment. Do not distribute externally without
authorization.**

Qualisera AI is being developed as proprietary software. These notes do not
establish inventorship, ownership, novelty, non-obviousness, patent eligibility,
or enforceable confidentiality. No patent application or grant is represented.

## Current implementation areas

The repository currently contains healthcare data loaders and validation code
for Synthea, FHIR, and NIH chest X-ray metadata, a mock API, automated tests, and
dashboard/reporting code. Descriptions of current features should be checked
against the implementation before being used in external materials.

## Before external disclosure

- Consult qualified patent counsel before publishing technical details,
  demonstrations, source code, or a proposed invention.
- Review prior public disclosures, including repository visibility, commits,
  releases, forks, package artifacts, websites, and shared documents. Local
  edits do not erase or change access to copies already distributed.
- Ask counsel to assess filing strategy, relevant dates, inventorship,
  ownership/assignment, prior art, and any jurisdiction-specific deadlines.
- Keep dated internal records of the problem addressed, technical approach,
  alternatives considered, implementation evidence, and contributors.
- Review each third-party library, standard, and dataset under its own license
  and terms; proprietary project status does not change those obligations.

These notes are for internal project organization only and are not a substitute
for advice from an intellectual-property attorney.
